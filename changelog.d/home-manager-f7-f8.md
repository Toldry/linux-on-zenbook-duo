### home-manager can set F7 and F8

- `zenduo.f7Terminal` and `zenduo.f8DarkMode` are new home-manager options,
  so F7 opening a terminal and F8 switching dark mode (or swapping windows)
  can be set declaratively like every other setting. `f7Terminal` defaults
  on and binds Super+P at activation, as `./install.sh` does. Not yet run
  under home-manager on the laptop
- the README and install guides now clone this repository rather than the
  one it was forked from
